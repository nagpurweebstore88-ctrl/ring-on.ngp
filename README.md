# Ring On.NGP store

Gothic accessories from Nagpur. Orders are sent on WhatsApp.

## Files
- `index.html` is the whole shop.
- `images/logo.png` and `images/favicon.png` are the Ring On logo.
- Product photos go in `images/`.

## Add a product
Open `index.html` and find `PRODUCTS`. Add one line per piece. Give it a new `id`.
Save the photo as `images/<name>.jpg` and put `<name>` in `image`.
The seven items already there are samples. Delete them before you publish.

## Change contact details
Edit `SHOP` at the top of the script: WhatsApp number, call number and Instagram name.

## Publish with GitHub Pages
Create a repository, upload these files, then open Settings, Pages, and publish from the `main` branch.
